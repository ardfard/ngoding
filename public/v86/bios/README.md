# BIOS images

`seabios.bin` and `vgabios.bin` are [SeaBIOS](https://www.seabios.org/) builds taken
unmodified from [v86](https://github.com/copy/v86/tree/cc37f35c43bf14865d74ad76879ecf9410f69eb1/bios)
(commit `cc37f35`).

SeaBIOS is licensed under the GNU LGPL v3 (`COPYING.LESSER`, which builds on the GNU GPL
v3 in `COPYING`).

Corresponding source: SeaBIOS tag `rel-1.16.2` (<https://git.seabios.org/seabios.git>),
built with v86's `seabios.config` and `fetch-and-build-seabios.sh` from the commit above.
